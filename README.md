# MaoLaoAPI教程

面向编程新手的 MaoLao API 使用文档站，包含基础接入和异步生图任务教程。

## 本地开发

```bash
pnpm install
pnpm docs:dev
```

## 构建

```bash
pnpm docs:build
```

## 已收录内容

- MaoLao API 新手快速开始、API Key、计费与额度。
- 常见工具接入教程。
- 异步生图任务、轮询和图片内容下载教程。
- [TypeSafe / Jev API](docs/typesafe-jev.md)：同步结构化判断、三种题型、鉴权、调用示例与错误处理。
