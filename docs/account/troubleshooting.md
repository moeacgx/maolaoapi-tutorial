# 账户问题排查

## 充值未到账

先检查：

1. 是否登录了正确账号。
2. 订单状态是否已完成。
3. 支付是否真的扣款成功。
4. 页面是否需要刷新或重新登录。

如果仍未到账，保存订单号、支付时间和金额，再联系站点支持。

## 额度消耗异常

常见原因：

- 某个客户端后台自动重试。
- 上下文太长。
- 使用了高倍率模型或高倍率分组。
- 图片、视频等固定消耗模型被多次调用。
- 多个工具共用同一个 Key，无法区分来源。

建议为不同工具创建不同 Key，并在控制台日志中按 Key 排查。

## 套餐额度不符合预期

检查套餐规则：

- 额度刷新周期。
- 未使用额度是否累计。
- 是否限制分组或客户端。
- 是否禁止分发或共享。

## API Key 无法使用

先确认 Key 没有被禁用、删除或超过额度上限。然后用 curl 直接测试，排除客户端配置问题。
