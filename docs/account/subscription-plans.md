# 订阅套餐选择

订阅套餐通常适合长期、稳定、高频使用。普通余额更适合临时使用、测试或不固定需求。

## 什么时候选订阅

适合订阅的情况：

- 每周或每月都有固定用量。
- 主要用于 Claude Code、Codex CLI、开发工具等高频场景。
- 希望获得某些套餐分组或周期额度。
- 能接受套餐规则中的刷新周期和使用限制。

不一定适合订阅的情况：

- 只是偶尔测试。
- 用量非常低。
- 不确定模型和工具是否能稳定满足需求。
- 需要把额度分发给多人使用，但套餐规则不允许。

## 选择套餐时看什么

| 项目 | 说明 |
| --- | --- |
| 周期 | 月卡、周卡或其他周期 |
| 刷新方式 | 额度是否按周或按月刷新 |
| 未用额度 | 是否累计到下个周期 |
| 支持分组 | 是否包含你要用的模型和客户端 |
| 使用限制 | 是否允许分发、共享或高风险用途 |

## 建议

新手可以先用普通余额测试 1 到 2 天，确认工具、模型和分组都适合自己，再考虑订阅套餐。
