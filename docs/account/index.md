# 账户概览

账户与订阅页面主要关注 MaoLao API 的余额、充值、套餐、订单和发票问题。

## 你需要关注的账户信息

| 项目 | 用途 |
| --- | --- |
| 余额 / 额度 | 判断还能调用多少模型 |
| 当前套餐 | 判断是否有周期额度或特殊分组权限 |
| API Key 用量 | 排查哪个工具消耗额度 |
| 订单记录 | 查询充值、套餐购买状态 |
| 发票信息 | 需要报销或记录时使用 |

## 新手建议

刚开始使用时，不建议直接把主 Key 放进很多工具。更稳妥的方式是：

1. 先充值或开通适合自己的套餐。
2. 为每个工具创建单独 API Key。
3. 给测试 Key 设置额度上限。
4. 每隔一段时间查看日志和余额变化。
