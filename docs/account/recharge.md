# 充值余额

充值余额用于普通 API 调用扣费。具体支付入口、支付方式和到账规则以 MaoLao API 控制台当前页面为准。

## 充值前确认

1. 已登录正确账号。
2. 知道自己要普通余额还是订阅套餐。
3. 充值前看清金额、到账额度和支付渠道。
4. 不要在多个浏览器标签页重复提交订单。

## 基本流程

1. 进入控制台的充值或个人中心页面。
2. 选择充值金额。
3. 选择可用支付方式。
4. 完成支付。
5. 返回控制台确认余额是否到账。
6. 如果未到账，保存订单号并查看订单记录。

## 余额和额度的关系

公开配置显示 MaoLao API 使用 quota 体系，并以 USD 方式展示额度。你在控制台看到的余额会在调用模型时根据模型倍率、分组倍率、输入输出长度或固定请求消耗扣减。

## 注意事项

- 充值后先小额测试，不要立即跑大批量任务。
- 充值不到账时不要连续重复支付同一订单。
- 如果使用兑换码或活动额度，注意是否有有效期或适用范围。
