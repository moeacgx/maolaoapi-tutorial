# OpenCat

OpenCat 是聊天客户端类工具。它能否接入 MaoLao API，取决于当前版本是否支持自定义 OpenAI API 地址。

## 下载地址

- 官方网站：[https://opencat.app](https://opencat.app)
- 新手建议：移动端版本可能和桌面端能力不同，配置前先确认是否有自定义 API 入口。

## 配置步骤

1. 打开 OpenCat 设置。
2. 找到 API、Provider 或 Model 设置。
3. Provider 选择 OpenAI 或 OpenAI Compatible。
4. API Key 填 MaoLao API Key。
5. Base URL 填 `https://api.maolaoapi.cc/v1`。
6. Model 填完整模型名。
7. 保存后发一句“请回复 ok”测试。

## 常见问题

- 如果只有官方 OpenAI Key 输入框，找一下是否有 Base URL 或 API Host 选项。
- 如果没有自定义地址入口，就不能直接使用 MaoLao API。
